4 Nguyên Tắc Kỹ Thuật Bất Biến

Học tập từ nhận xét của Andrej Karpathy về các lỗi điển hình của LLM khi viết code: bớt đoán mò, tối giản, và sửa đúng chỗ.

01 / DISCIPLINE

Think Before Coding

Không được tự giả định nếu yêu cầu mơ hồ. Nêu rõ các giả định, đánh đổi và hỏi lại trước khi viết mã.

02 / MINIMALISM

Simplicity First

Chỉ viết lượng code tối thiểu giải quyết bài toán. Tuyệt đối không thêm abstraction hay suy đoán tương lai.

03 / PRECISION

Surgical Changes

Chỉ sửa đúng phạm vi yêu cầu. Giữ nguyên style của codebase. Mọi dòng code thay đổi đều phải truy vết được.

04 / SAFETY

Strict Isolation

Mọi gói phụ thuộc phải nằm trong môi trường ảo (.venv) cục bộ của workspace. Nghiêm cấm làm bẩn host system.

Khởi Động agent_setup Trong 3 Bước

Cấu hình nhẹ gọn, nạp trực tiếp vào dự án của bạn và chạy cùng Antigravity CLI.

Terminal Quickstart cho Antigravity 
# 1. Clone repository hoặc copy cấu hình cốt lõi vào root dự án
git clone https://github.com/phamvantienkiz/agent_setup.git
cp -r agent_setup/.agents agent_setup/AGENTS.md ./your-project/

# (Tùy chọn) Nếu làm nghiên cứu khoa học, nạp thêm từ gói on-demand:
# cp -r agent_setup/cs-research-skills/paper-lookup ./your-project/.agents/skills/
# cp -r agent_setup/microsoft-research/rs-paper-search ./your-project/.agents/skills/

# 2. Khởi tạo môi trường ảo Python biệt lập (Strict Environment Isolation)
cd ./your-project
python -m venv .venv
source .venv/bin/activate  # Hoặc trên Windows: .venv\Scripts\activate

# 3. Kích hoạt Antigravity CLI và tận hưởng kho 50+ Skills
